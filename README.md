# Physique Pathway

A single-page coaching dashboard for fitness coaches to track client progress, check-ins, nutrition, and payments.

## What it does

- **Client overview** — at-a-glance table of all clients with phase, weight trend, check-in status, and payment standing
- **Client detail pages** — per-client deep dive with weight chart, biometrics, macro targets, and session notes
- **Alerts** — flags overdue check-ins and missed payments so nothing slips through the cracks

## Tech stack

Pure HTML, CSS, and vanilla JavaScript — no build step, no dependencies.

## Getting started

Open `physique_pathway_dashboard.html` directly in any modern browser. No server required.
